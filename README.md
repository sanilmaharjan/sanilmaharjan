# 💫 About Me:
Hi, I'm Sanil Maharjan.  
🎓 Currently pursuing my Bachelor of Computer Applications (BCA) at NCCS (National College of Computer Studies) in Kathmandu.  
🏫 Completed +2 from NCCS Higher Secondary School and SEE from Green Peace Co-Ed School.  

With a strong programming foundation, my primary technical focus is on **Quality Assurance (QA), testing, and automation**, complemented by solid experience in **Frontend Development**.

💻 Skills, Certifications & Achievements:  
- **QA & Automation:** Selenium (E2E web automation), PyTest, Postman (API testing), Jenkins (CI/CD), Newman, Thunder Client  
- **Frontend Development:** HTML5, CSS3, JavaScript, React, Bootstrap, Tailwind CSS, Responsive Design  
- **Backend & Databases:** Python, PHP, Flask, MySQL, MongoDB (Basic), Node.js (Introductory)  
- **Tools & Workflows:** Git, GitHub, VS Code, Figma, Page Object Model (POM), Data-Driven Testing  
- **Certifications:** - Python Selenium Certificate (Udemy)
  - Webpage Designing & Graphic Designing Certifications (Computer Planet, 2020)
- **Achievements & Presentations:** - 2nd Runner-Up, NCCS Business Hackathon (Service Mitra, April 2026)
  - NCCS Academic Presentations: Python Song Popularity Prediction (2025), UI/UX Booking Website (2025), Scripting Language School Website (2025), DSA Calculator (2024), C-Programming Quiz Gamer (2024), and Internet (2023).

📂 Notable Projects:  
- **E2E Test Automation Framework:** Built a robust UI testing framework using Python and Selenium, implementing the Page Object Model (POM), data-driven testing, and Jenkins CI/CD integration.
- **API Testing & Verification:** Conducted structured API testing using Postman (variables, collection runners, Newman reports) and Thunder Client for REST endpoint verification.
- **Service Mitra (2nd Runner-Up):** Developed the React frontend for a bidding-based local work marketplace.
- **Hello Weather Dashboard:** Created a dynamic weather app using React, Open-Meteo API, and AI-generated Tailwind CSS styling, deployed on Vercel.
- **Typing Practice System (6th Sem):** Developed a Python (Flask) application applying N-Gram and K-Means Clustering algorithms to analyze user typing patterns.
- **Booking & Reservation Systems:** Developed functional PHP/MySQL systems integrating Khalti and eSewa digital payment gateways.

🎯 Learning & Interests:  
- Advancing my knowledge in QA workflows, test automation techniques, and CI/CD pipelines.
- Building clean, responsive UI architectures.
- Actively searching for testing resources to expand my QA expertise and automation methodologies.
- Utilizing AI-assisted workflows to accelerate development and problem-solving.
